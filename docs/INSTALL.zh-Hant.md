# 安裝與使用 FoldPatch

[English](INSTALL.en.md) · [한국어](INSTALL.md) · [日本語](INSTALL.ja.md) · [简体中文](INSTALL.zh-Hans.md) · **繁體中文**

[返回 README](../README.zh-Hant.md)

FoldPatch 目前為早期 Alpha 版本。實機驗證環境為 **Galaxy Z Fold3（SM-F926N）· Android 15 / One UI 7**。Android 16/17 僅在模擬器上測試。長時間使用以及所有系統介面切換尚未驗證。Android 14 是最低安裝版本，並不代表支援所有裝置。[相容性與驗證紀錄（英文）](COMPATIBILITY.en.md)。

## 1. 取得 APK

請使用可安裝的 **`foldpatch-release.apk`**，無需自行編譯。點選 **[下載 APK](https://github.com/att083/FoldPatch/releases/download/v0.1.0-alpha.4/foldpatch-release.apk)** 取得安裝檔案。「Source code (zip)」不能安裝到 Android 上，以 `-unsigned.apk` 結尾的檔案也不是提供給使用者的發布版。

開啟 APK 時，Android 可能要求允許瀏覽器或檔案管理應用程式安裝應用程式。請僅在信任檔案來源時允許。兩個 APK 使用相同簽署金鑰時，可以保留設定直接更新。開發版和公開版可能使用不同金鑰；遇到簽署不符時，不要為了略過錯誤直接解除安裝舊版。

## 2. 選擇觸控正常的一側

開啟 FoldPatch，首次設定會詢問 **內側螢幕**哪一側觸控正常。可以摺疊手機，在外側螢幕完成這一步。在內側螢幕上，初始操作控制項位於左右兩端。

設定、觸控板、工具列和鍵盤會放到所選的一側。這不會交換應用程式位置，也不會改變可見寬度。以後更改此設定時，需要在新的一側確認；未確認的變更會在 15 秒後還原到原來的一側。

## 3. 準備 Shizuku

FoldPatch 需要透過獨立應用程式 Shizuku 使用系統顯示和輸入功能。**不需要 root，也不需要一直連接電腦。**

引導會略過已完成的步驟，提示你完成剩餘準備：

1. 從 [官方下載頁面](https://shizuku.rikka.app/download/)安裝 Shizuku，然後返回 FoldPatch。
2. 開啟 Android 開發人員選項。Samsung 手機通常在 **設定 → 關於手機 → 軟體資訊** 中連續點選 **版本號碼**；如有要求，請解鎖。
3. 連接 **可信任的 Wi-Fi**，在開發人員選項中開啟 **無線偵錯**。
4. 在 Shizuku 中進入 **透過無線偵錯啟動 → 配對**。開啟 Android 使用配對碼配對裝置的畫面，將配對碼輸入 **Shizuku 通知**，而不是 FoldPatch。如果這一步需要通知權限，請允許 Shizuku 傳送通知。
5. 返回 Shizuku，點選 **啟動**。確認顯示正在執行後，返回 FoldPatch。
6. 在 Shizuku 權限提示中允許 FoldPatch。如果之前拒絕過，可以重試或從 Shizuku 的已授權應用程式清單中更改。

不同手機的系統選單名稱可能不同，請視需要參考 [Shizuku 官方設定指南](https://shizuku.rikka.app/guide/setup/)。不要在問題回報中公開配對碼或 Wi-Fi 密碼。恢復連線不要求使用公共 Wi-Fi。

**手機重新啟動後：** 非 root 方式啟動的 Shizuku 服務會停止，可能需要手動重新啟動。有條件的自動啟動不代表在任何環境中都能自動恢復。FoldPatch 會保留螢幕範圍和偏好設定，重新啟動 Shizuku 後無需從頭調整。

**日常使用時：** FoldPatch 與 Shizuku 的連線在手機本機完成，與電腦的無線 ADB 連線不同。Fold3 已通過短時間中斷 Wi-Fi 的測試，但並未驗證所有電源和網路條件。如果 Shizuku 停止，請按重新連線的提示操作；FoldPatch 無法取代 Shizuku 的啟動流程。

## 4. 授予權限並準備鍵盤

在 FoldPatch 的設定引導中：

1. 允許 **顯示在其他應用程式上層**，然後返回。
2. 閱讀無障礙服務說明，如要繼續使用，請同意。
3. 閱讀鍵盤切換說明，如要繼續使用，請同意。

開啟 FoldPatch 時，會透過 Shizuku 啟用 FoldPatch 的無障礙服務並切換至單側鍵盤。摺疊手機或關閉 FoldPatch 時，會嘗試還原之前的鍵盤。你可以不同意並退出引導，但此時尚未完成使用準備。

公開發布版沒有網際網路權限、廣告或分析 SDK，不儲存螢幕影像或輸入的文字。少量本機執行診斷紀錄包含技術狀態資訊。[隱私與權限詳情（英文）](../PRIVACY.en.md)。

## 5. 調整可見寬度

直向展開手機並解鎖，開啟 FoldPatch，然後進入 **調整螢幕範圍**。

- 刻度以 **未經調整的實際螢幕**為準：兩側各自的外側邊緣是 **0%**，中間是 **50%**。
- 使用觸控正常一側的兩個滑桿和 ± 按鈕，分別設定從左右外側邊緣向內可見的寬度。每側範圍為 20–50%，每次微調 0.5%。
- 開啟預覽，確認合適後點選 **儲存此範圍**。未儲存時會在 15 秒後還原之前的範圍。
- 完成指標與工具列練習後，返回平常使用的應用程式。

如果整個螢幕都能顯示，請設為 **左側 50% · 右側 50%**。這樣會保留原來的全寬畫面，不留中間空隙，同時仍可用觸控板操作另一側或整個螢幕。如果兩側觸控都正常，選擇更方便的一側即可。

FoldPatch 會記住已完成的準備。如果 Shizuku 之後停止，只會提示需要重新完成的步驟，不會清除螢幕設定。

## 6. 使用觸控板

在工具列中選擇觸控正常的一側，可以直接觸摸操作這一側。選擇另一側或整個螢幕時，觸控正常的一側就會變成觸控板。

| 操作 | 在觸控正常一側使用的手勢 |
| --- | --- |
| 移動 / 點擊 | 單指移動 / 不移動手指，輕點一下。 |
| 拖曳 | 輕點一次，再次按住並移動；也可以按住直到震動提示後再移動。 |
| 長按 | 將指標對準目標，保持按住。 |
| 捲動 | 雙指一起上下、左右或斜向移動。 |
| 縮放 | 將指標對準目標，然後雙指張開或捏合。 |
| 按兩下 | 在同一位置快速輕點兩次。 |

手勢的具體效果取決於被操作的應用程式。只有支援縮放的內容才能縮放。

點按工具列把手，可依序切換單一按鈕、所選按鈕和全部按鈕；拖曳把手可移動工具列。可調整大小、方向、顯示的按鈕和指標速度，並記住展開狀態及左右兩側各自的位置。從最下邊緣向上滑動會作為系統手勢處理，一般觸控板操作請從區域內部開始。系統手勢的支援情況仍受上述裝置與系統驗證範圍限制。

選擇任一輸入欄位即可使用單側鍵盤。**鍵盤僅支援韓語和英語，不支援日語或中文輸入。** 在輸入欄位允許的情況下，可使用剪下、複製、貼上、全選和游標移動。複製或剪下前，請先選取文字。不包含自動完成、語音輸入或剪貼簿歷程記錄。

## 還原、關閉與解除安裝

| 情況 | 處理方式 |
| --- | --- |
| 正在重新連線 | 稍等片刻。如果 Shizuku 仍在執行且已授權，FoldPatch 可以重新連線。 |
| Shizuku 已停止 / 未授權 | 啟動 Shizuku 或授權 FoldPatch，然後重試「檢查 Shizuku 連線」。 |
| 無法觸及工具列 | 摺疊手機，在外側螢幕開啟 FoldPatch 設定。 |
| 螢幕範圍不正確 | 未儲存的預覽可等待逾時還原；已儲存的變更，可在「說明與還原」中選擇「還原上次儲存的範圍」。 |
| 想停止使用 | 關閉「使用 FoldPatch」。若不希望自動恢復使用，也關閉「展開時自動開啟」。其他應用程式不會被關閉。 |
| 意外退出後顯示仍異常 | 稍等片刻，若未恢復，摺疊手機並在外側螢幕開啟 FoldPatch。必要時重新啟動手機。 |
| 沒有還原之前的鍵盤 | 在 Samsung 設定 → 一般管理 → 鍵盤清單及預設中重新選擇。 |

解除安裝前，請先關閉 FoldPatch 和自動開啟，確認螢幕與鍵盤恢復正常。解除安裝會刪除 FoldPatch 的設定，但不會解除安裝 Shizuku。配對、權限和首次安裝都需要你本人確認，應用程式不會在未經同意的情況下授予自己權限。

介面語言跟隨 Android 設定，支援韓語、英語、日語、簡體中文和繁體中文。切換介面語言不會增加日語或中文鍵盤輸入支援。

# FoldPatch · 폴드패치

**갈라진 화면을 이어, 계속 쓰도록.**

English: **Bridge the split. Keep using your phone.**

## 누구를 위한 앱인가

가운데 화면이 갈라지거나 한쪽 터치가 고장 나도 지금의 폴더블을 계속 써야 하는 사람을 위한 디지털 반창고입니다. 사용자의 경제 사정을 단정하지 않습니다. 손상 구간을 피해 앱 내용을 이어 보여 주고, 정상 터치 쪽으로 화면 전체를 조작할 수 있게 돕습니다.

하드웨어 수리나 모든 기기에서의 동작을 약속하지 않습니다. 실제 지원 범위와 Shizuku 요구사항은 [설치 안내](INSTALL.md)를 따릅니다.

## 이름과 문구

- 영문 표기는 **FoldPatch**, 한글 표기는 **폴드패치**입니다. `Fold Patch`, `Foldpatch`, `폴드 패치`로 나누거나 대소문자를 바꾸지 않습니다.
- 앱 목록·권한·키보드·알림 이름은 한국어에서 폴드패치, 그 밖의 지원 언어에서 FoldPatch입니다. 설정 첫 화면의 로고 글자는 FoldPatch로 통일합니다.
- 브랜드 문구는 첫 화면과 README에 사용합니다. 조작바와 키보드에는 장식이나 홍보 문구를 더하지 않습니다.
- 앱의 켜짐과 사용 여부는 **폴드패치 사용 / 폴드패치 켜기 / 펼치면 자동으로 켜기**로 표현합니다. 별도의 “도우미” 제품명은 사용하지 않습니다. 영어는 **Use FoldPatch / Turn on FoldPatch / Turn on when unfolded**로 맞춥니다.
- 화면 범위 맞추기·터치패드·키보드·Shizuku 연결처럼 구별이 필요한 기능과 외부 앱의 이름은 유지합니다.

## 현재 시각 체계

아이보리 배경과 오렌지 강조색을 사용합니다. 설정, 첫 실행 안내, 조작바, 키보드, 화면 범위 조정에 같은 색상과 네이티브 컨트롤을 적용합니다.

| 용도 | 색 |
| --- | --- |
| 기본 배경 | `#FFFAF4` |
| 상태 패널·보조 버튼 | `#F5EBE0` |
| 주요 동작·선택 강조 | `#BD471D` |
| 기본 글자 | `#32231D` |
| 보조 글자 | `#79675B` |
| 구분선 | `#E5D7CA` |
| 키보드 키 | `#FFFDF9` |

- 로고 글자는 짙은 갈색으로 통일하고 아이콘의 오렌지를 강조색으로 사용합니다.
- 첫 화면은 항목 이름과 필요한 현재 값만 표시합니다. 반복 설명은 줄이고 권한·복구·첫 실행에 필요한 안내는 유지합니다. 설정 요약은 각 상세 화면 및 접근성 설명에서도 확인할 수 있습니다.
- 큰 장식 그림보다 정상 터치 영역 안의 조작 가능성을 우선합니다. 좁은 화면에서는 이름을 유지하고 헤더 아이콘을 숨깁니다.
- 기본 글꼴은 Android의 sans-serif 및 시스템 언어별 폴백입니다. 주요 버튼은 14dp 곡률, 상태 패널은 20dp 곡률을 사용합니다. 조작바·키보드의 사용자 크기와 입력 영역은 유지합니다.
- 키보드는 별도 설정 화면 없이 사용합니다. 키 입력 진동은 항상 요청하되 휴대폰의 시스템 진동 설정을 따릅니다. 기존 앱의 진동 끄기 값은 더 이상 사용하지 않습니다. 첫 사용 과정의 키보드 안내와 키보드 자체의 한/영 전환·편집·숨기기는 유지합니다.
- 화면 재배치와 입력 로직은 시각 디자인과 별개로 유지합니다.

## 아이콘과 이미지

오렌지·코럴 바탕에 아이보리 두 화면과 오렌지 패치가 겹치는 아이콘입니다.

- [foldpatch_mark.png](../res/drawable-nodpi/foldpatch_mark.png): 설정 헤더에 쓰는 원본 PNG. 헤더의 둥근 모서리는 네이티브 마스크입니다.
- [foldpatch_launcher.png](../res/drawable-nodpi/foldpatch_launcher.png): Android 런처 마스크에 맞춰 여백을 확장한 PNG. 두 화면을 중앙 약 52% 안에 배치합니다. adaptive icon의 배경 레이어에 넣고 전경은 투명하게 유지하여 그림 전체가 함께 움직입니다.
- [foldpatch-cover.png](media/foldpatch-cover.png): README의 브랜드 표지입니다.
- Android 알림·빠른 설정의 작은 기능 아이콘은 기존 시스템 아이콘을 사용합니다. 테마용 단색 아이콘은 별도로 제공하지 않습니다.

### 출처와 교체

아이콘과 표지는 OpenAI Image Generation으로 제작한 래스터 이미지이며 별도의 벡터 원본은 없습니다. README의 앱 스크린샷 세 장은 Galaxy Z Fold3 / Android 15에서 캡처한 원본입니다. 프로젝트의 이미지에도 루트 [Apache License 2.0](../LICENSE)을 적용합니다. 외부 기능 아이콘의 출처는 [외부 코드·라이브러리 고지](../THIRD_PARTY_NOTICES.md)를 따릅니다.

교체 시 두 자산을 함께 확인하고, debug APK의 작은 런처 아이콘·원형 마스크·설정 헤더를 검사합니다. 공개 소스 묶음은 `python3 scripts/prepare-public.py`로 다시 생성합니다. PNG는 자동 포함됩니다.

## 업데이트 호환성

개발 당시 이름은 ReachPad였습니다. 기존 설치에 그대로 업데이트하도록 `dev.reachpad` 패키지, Android 컴포넌트 이름, 환경변수 `REACHPAD_*`, 설정 키, Binder 식별자, 복구 파일, 서명 키는 유지합니다. 기존 설치를 삭제하거나 데이터 마이그레이션을 요구하지 않습니다.

새 배포 파일명은 `foldpatch-debug.apk`, `foldpatch-release-unsigned.apk`, 서명 후 `foldpatch-release.apk`입니다. 소스 묶음은 `foldpatch-source.zip`이며 ZIP 내부 최상위 폴더는 `FoldPatch/`입니다. 이름 변경만으로 과거 APK 파일의 내용이 갱신되지는 않습니다.

공개 웹 검색에서 같은 이름의 앱·서비스를 발견하지 못했으나, 상표 등록이나 도메인 확보를 완료한 상태는 아닙니다.

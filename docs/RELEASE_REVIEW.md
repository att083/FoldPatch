# 현재 검증 결과

[English](RELEASE_REVIEW.en.md) · [호환성 상세](COMPATIBILITY.md) · [개발 단계별 이력](research/2026-09-20-development-history.md)

대상: **v0.1.0-alpha.4**, 정리일 2026-09-20. GitHub 첫 공개를 준비하는 초기 시험판입니다. **실기기 확인은 삼성 Galaxy Z Fold3 / Android 15 / One UI 7이며, Android 16·17은 가상 기기만 확인했습니다.**

## 확인된 범위

| 항목 | 실제 확인 내용 | 해석의 한계 |
| --- | --- | --- |
| Fold3 일상 조작 | 기존 앱 재배치, 클릭·스크롤·드래그, 한쪽 키보드, 최근 앱·알림창, 접기 후 외부 화면 복구 | 개발 중 누적 확인. 모든 항목을 최종 버전에서 한꺼번에 재시험한 결과는 아님 |
| 최신 50% 범위 | Fold3 설정 화면에서 양쪽 50% 저장·이전 범위 복귀. Fold3/Android 17의 실제 입력 경로로 양끝 좌표·확대·길게 누르기 자동 확인 | 합성 입력 스트림은 손가락 감각이나 손상 패널 시험을 대체하지 않음 |
| Android 15·16·17 가상 기기 | 통합 재배치, 비대칭 범위, 강제 종료·소유권 상실 후 복구. Android 16·17 입력·키보드 편집 | 삼성 화면 구조·물리적 접힘·최신 One UI 실기기는 미검증 |
| 사용 준비 | Android 15·16에서 Shizuku 무선 페어링·권한 거절/재시도·범위 저장·재시작 후 복귀 | 삼성 새 설치와 개발자 도움 없는 초보자 사용성 시험은 남음 |
| 연결 유지 | Fold3에서 약 120초 Wi-Fi·무선 디버깅 끊김 중 실제 클릭, 약 1분 화면 끄기 뒤 복귀 | USB 디버깅은 켜 둔 조건. 외출·온종일 대기·재부팅 뒤 자동 시작 보장이 아님 |
| 공개 APK | 별도 배포 키로 서명 검증. Android 17 가상 기기의 새 설치·첫 실행 및 업데이트 후 준비 단계 유지 | 기존 삼성 폰은 데이터를 보존하는 개발 서명 업데이트로 확인 |
| 브라우저 설치 | Android 17 가상 기기 Chrome에서 APK 다운로드 → 출처 허용 → Android 설치 → 열기 → 첫 설정 화면. 다운로드 해시·버전·디버깅 비활성 확인 | 로컬 HTTP 서버에서 받은 시험. 실제 GitHub HTTPS 다운로드 및 삼성 새 설치 확인은 아님 |

Android 17은 초기 경로가 실패했지만, 이후 시스템 소유권을 유지하는 대체 경로를 통합해 위 시험을 통과했습니다. 과거 기록의 ‘미지원’ 문장은 당시 단계에 대한 설명입니다. Android 17의 하단 제스처·작업표시줄과 다른 제조사 화면은 여전히 추가 확인이 필요합니다.

## 소스와 배포 파일

- 공개용 ZIP만 별도 폴더에 풀어 테스트 9종·release 검사·221개 문자열 × 6개 리소스 검사와 release 빌드를 통과했습니다.
- 재빌드한 APK와 서명된 후보의 manifest·DEX·리소스·라이선스 등 파일 내용이 일치합니다. 서명과 ZIP 메타데이터를 제외한 비교이며 APK 전체가 바이트 단위로 동일하다는 뜻은 아닙니다.
- release는 디버깅 불가이며 개발 시험 진입점이 제외됩니다. 인터넷 권한이 없고, 고정 의존성 해시와 라이선스를 검사합니다.
- GitHub Actions에 같은 호스트 검사·unsigned release 빌드·공개 파일/문서 링크 검사를 구성했습니다. 워크플로 문법 검사와 공개 소스에서의 동일 명령 실행을 통과했습니다. **원격 GitHub 실행 결과는 아직 없습니다.**

## 아직 남은 확인

공개 저장소·릴리스 URL과 실제 다운로드, 서명 키의 별도 백업, 삼성 새 설치와 초보자 안내 시험은 공개 준비에서 별도로 확인합니다. Android 16·17 실기기, 장시간 발열·배터리, 보호 콘텐츠·통화·모든 시스템 전환도 미검증입니다. 화면 읽기 기능과 동시 사용 및 가로 화면은 지원하지 않습니다.

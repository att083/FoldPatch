# v0.1.0-alpha.4 — 첫 공개 시험판

[English](RELEASE_NOTES.en.md) · [설치·복구](INSTALL.md) · [검증 결과](RELEASE_REVIEW.md)

폴드패치는 가운데가 보이지 않는 폴드폰에서 기존 앱을 이어 보고, 터치가 되는 쪽의 터치패드와 키보드로 조작하는 앱입니다. 초기 시험판이며 패널 수리나 모든 폴드 기기 지원을 의미하지 않습니다.

## 포함된 기능

- 가운데 손상 구간을 뺀 폭으로 기존 앱 재배치. 내용을 가로로 찌그러뜨리거나 별도 작업 공간으로 옮기지 않습니다.
- 정상 터치 쪽 선택, 반대쪽·전체 화면 커서 조작, 클릭·드래그·길게 누르기·두 손가락 스크롤·핀치 확대.
- 정상 쪽의 한글·영문 키보드, 누를 때 진동, 기본 편집 도구.
- 포인터 속도·모양과 조작바 크기·방향·버튼 설정. 조작바 세 단계 및 마지막 상태·위치 기억.
- 각쪽 20~50% 범위, 실제 화면 눈금, 미리보기 시간 만료 시 원복, 이전 범위 복구. 양쪽 50%이면 원래 전체 화면에서 터치패드만 사용.
- Shizuku·권한의 단계별 준비, 연결 복구, 접거나 끌 때 정상 화면 복원.
- 한국어·영어·일본어·중국어 간체/번체 UI, Android 15·16·17 화면 처리 경로 통합.

## 설치 전 확인

첫 공개 전에 앱 ID를 `dev.foldpatch`로 확정했습니다. 이전 ID의 개발용 설치와는 별도 앱이며 설정과 권한이 자동으로 이전되지는 않습니다.

**Shizuku 설치·실행·권한 허용이 필요합니다.** 비루팅 Shizuku는 재부팅하면 종료되며 다시 시작해야 할 수 있습니다. 루팅이나 상시 PC 연결은 필요하지 않습니다. [설치 안내](INSTALL.md)를 먼저 읽어 주세요.

실기기 확인은 **삼성 Galaxy Z Fold3 / Android 15 / One UI 7**입니다. **Android 16·17은 가상 기기만 확인했습니다.** alpha.4 APK는 Android 14에 설치할 수 있었지만 Android 14는 지원하지 않습니다. Android 15 이상이 필요하며 다른 모델은 미검증입니다. [호환성과 제한](COMPATIBILITY.md)을 확인하세요.

가로 화면과 화면 읽기 기능 동시 사용은 지원하지 않습니다. 키보드 입력은 한글·영문만 지원합니다. 보호 콘텐츠·통화·장시간 발열과 배터리·모든 시스템 전환은 검증이 더 필요합니다. 기존 삼성 화면 구조에서는 알림창이 축소 표시될 수 있습니다.

## 배포 파일

[릴리스](https://github.com/att083/FoldPatch/releases/tag/v0.1.0-alpha.4)에서 다음 파일을 받을 수 있습니다.

| 파일 | 용도 |
| --- | --- |
| `foldpatch-release.apk` | 서명된 설치용 앱 |
| `foldpatch-release.apk.sha256` | 해당 APK의 SHA-256 체크섬 |
| `foldpatch-source.zip` | 공개 소스·검사·빌드 안내. 설치 파일이 아닙니다. |

기존 개발 APK는 서명이 다를 수 있습니다. 서명 오류를 피하려고 자동으로 삭제하지 마세요. 삭제하면 설정이 사라집니다. 정상 업데이트에는 같은 배포 서명 키가 필요합니다.

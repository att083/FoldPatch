# FoldPatch のインストールと使い方

[English](INSTALL.en.md) · [한국어](INSTALL.md) · **日本語** · [简体中文](INSTALL.zh-Hans.md) · [繁體中文](INSTALL.zh-Hant.md)

[README に戻る](../README.ja.md)

FoldPatch は初期アルファ版です。実機で確認した環境は **Galaxy Z Fold3（SM-F926N）・Android 15 / One UI 7** です。Android 16/17 はエミュレーターのみで確認しています。長時間の使用やすべてのシステム画面遷移は未検証です。インストールには Android 14 以上が必要ですが、すべての端末への対応を意味するものではありません。[対応状況と検証記録（英語）](COMPATIBILITY.en.md)。

## 1. APK を入手する

インストール用の **`foldpatch-release.apk`** を使います。自分でビルドする必要はありません。現在は初回の GitHub リリースを準備中です。公開後、リポジトリの **Releases → Assets** から入手してください。「Source code (zip)」は Android にインストールできません。`-unsigned.apk` で終わるファイルも一般利用向けリリースではありません。

APK を開くと、Android からブラウザーやファイルアプリによるインストールの許可を求められることがあります。入手元を信頼できる場合のみ許可してください。同じ署名鍵の APK なら設定を保持したまま更新できます。開発版と公開版では署名鍵が異なる場合があります。署名の不一致を回避するために、既存アプリを安易にアンインストールしないでください。

## 2. タッチできる側を選ぶ

FoldPatch を開くと、初期設定で **内側画面**のどちらがタッチできるかを選びます。端末を閉じたまま、外側画面で設定してもかまいません。内側画面では、最初の操作ボタンを左右両端に配置しています。

選んだ側に設定・タッチパッド・ツールバー・キーボードを配置します。アプリの左右を入れ替えたり、表示幅を変更したりする設定ではありません。後から変更する場合は、変更先の側で確認してください。確認しないと 15 秒後に元の側へ戻ります。

## 3. Shizuku を準備する

FoldPatch は画面表示と入力に関するシステム機能を利用するため、別アプリの Shizuku が必要です。**root 化やパソコンの常時接続は不要です。**

設定済みの手順はスキップされ、残りの準備が案内されます。

1. [公式ダウンロードページ](https://shizuku.rikka.app/download/)から Shizuku をインストールし、FoldPatch に戻ります。
2. Android の開発者向けオプションを有効にします。Samsung 端末では **設定 → 端末情報 → ソフトウェア情報** の **ビルド番号**を繰り返しタップします。求められたらロックを解除します。
3. **信頼できる Wi-Fi** に接続し、開発者向けオプションで **ワイヤレスデバッグ**をオンにします。
4. Shizuku のワイヤレスデバッグによる起動からペアリングに進みます。Android のペア設定コードを使う画面を開き、コードを **Shizuku の通知**に入力します。FoldPatch に入力するのではありません。必要に応じて Shizuku の通知を許可してください。
5. Shizuku に戻って **「開始」**を押し、実行中であることを確認してから FoldPatch に戻ります。
6. Shizuku の権限確認で FoldPatch を許可します。以前拒否した場合は再試行するか、Shizuku の許可済みアプリ一覧から変更してください。

システム上の名称は端末によって異なります。手順が合わない場合は [Shizuku 公式ガイド](https://shizuku.rikka.app/guide/setup/)を参照してください。不具合報告にペア設定コードや Wi-Fi パスワードを載せないでください。復旧のために公共 Wi-Fi を使う必要はありません。

**端末の再起動後：** root を使わない Shizuku のサービスは停止するため、起動し直す必要がある場合があります。条件付きの自動起動は、どこでも自動復旧できるという保証ではありません。FoldPatch は画面範囲と設定を保持するので、Shizuku を再起動しても最初から調整し直す必要はありません。

**普段の使用中：** FoldPatch と Shizuku の接続は端末内で完結し、パソコンのワイヤレス ADB 接続とは別です。Fold3 では短時間の Wi-Fi 切断中も動作を確認しましたが、すべての電源・通信条件を検証したわけではありません。Shizuku が停止した場合は接続案内に従ってください。FoldPatch が Shizuku の起動手順を代行できるわけではありません。

## 4. 権限とキーボードを準備する

FoldPatch の初期設定で、次の順に進めます。

1. **他のアプリの上に表示**を許可し、戻ります。
2. ユーザー補助機能の説明を読み、使用する場合は同意します。
3. キーボード切り替えの説明を読み、使用する場合は同意します。

FoldPatch をオンにすると、Shizuku を通じて FoldPatch のユーザー補助サービスを有効にし、片側キーボードに切り替えます。端末を閉じるか FoldPatch をオフにすると、以前のキーボードへの復元を試みます。同意せずに初期設定を終了することもできますが、その場合は使用準備が完了しません。

公開用リリースにはインターネット権限、広告、アクセス解析 SDK はなく、画面画像や入力した文章を保存しません。小規模なローカル診断記録には技術的な動作状態を記録します。[プライバシーと権限の詳細（英語）](../PRIVACY.en.md)。

## 5. 見える範囲を合わせる

端末を縦向きに開いてロックを解除します。FoldPatch をオンにし、**「画面範囲を調整」**に進みます。

- 目盛りは **表示を加工していない実際の画面**を基準とします。左右それぞれの外側の端が **0%**、中央が **50%** です。
- タッチできる側の 2 本のスライダーと ± ボタンで、各端から内側へ見える幅を指定します。各側は 20–50%、0.5% 刻みです。
- プレビューを開き、合っていれば **「この範囲で保存」**を押します。保存しない場合は 15 秒後に以前の範囲へ戻ります。
- ポインターとツールバーの練習を終えたら、いつものアプリに戻ります。

画面全体が映る場合は **左 50%・右 50%** にします。中央に隙間を設けず元の全幅の画面を表示したまま、タッチパッドで反対側や画面全体を操作できます。左右ともタッチできる場合は、使いやすい側を選んでください。

完了した準備は保存されます。後で Shizuku が停止しても、画面設定は消えず、再開に必要な準備だけが案内されます。

## 6. タッチパッドを使う

ツールバーでタッチできる側を選ぶと、その側を普通に直接操作できます。反対側または画面全体を選ぶと、タッチできる側がタッチパッドになります。

| 操作 | タッチできる側でのジェスチャー |
| --- | --- |
| 移動・クリック | 1 本指で動かす・動かさずタップする。 |
| ドラッグ | 1 回タップした後、もう一度触れて押したまま動かす。または振動するまで押したまま待ち、動かす。 |
| 長押し | 対象にポインターを合わせ、指を置いたまま待つ。 |
| スクロール | 2 本指を一緒に縦・横・斜めに動かす。 |
| 拡大・縮小 | 対象にポインターを合わせ、2 本指を広げる・つまむ。 |
| ダブルクリック | 同じ場所を素早く 2 回タップする。 |

実際の反応は操作先のアプリによって異なります。拡大・縮小には対応するコンテンツが必要です。

ツールバーのハンドルをタップすると、ボタン 1 個・選択したボタン・すべてのボタンの順に切り替わります。ハンドルをドラッグすると移動できます。大きさ・向き・表示するボタン・ポインター速度を調整でき、開き具合と左右それぞれの位置を記憶します。下端からのスワイプはシステム操作として処理するため、普通のタッチパッド操作は領域の内側から始めてください。システムジェスチャーの対応範囲には、前述の端末・OS ごとの検証上の制限があります。

入力欄を選ぶと片側キーボードを使えます。**入力できるのは韓国語と英語のみで、日本語・中国語の文字入力には対応していません。** 編集ツールは、入力欄が対応している範囲で切り取り・コピー・貼り付け・すべて選択・カーソル移動ができます。コピーや切り取りの前に文字を選択してください。入力候補、音声入力、クリップボード履歴はありません。

## 復元・停止・アンインストール

| 状況 | 対処方法 |
| --- | --- |
| 再接続中 | 少し待ちます。Shizuku が実行中で権限もあれば、FoldPatch は再接続できます。 |
| Shizuku が停止・権限がない | Shizuku を起動するか FoldPatch を許可し、「Shizuku接続を確認」をもう一度押します。 |
| ツールバーに触れない | 端末を閉じ、外側画面で FoldPatch の設定を開きます。 |
| 画面範囲が合わない | 未保存のプレビューは時間切れを待ちます。保存済みの場合は「ヘルプと復元」から「以前の範囲に戻す」を選びます。 |
| 使用をやめたい | FoldPatch をオフにします。再び自動でオンにしたくない場合は「開くと自動でオン」もオフにします。他のアプリは終了しません。 |
| 異常終了後、画面が元に戻らない | 少し待ち、戻らなければ端末を閉じて外側画面で FoldPatch を開きます。必要に応じて端末を再起動します。 |
| 以前のキーボードに戻らない | Samsung の設定 → 一般管理 → キーボードリストと初期設定から選び直します。 |

アンインストール前に FoldPatch と自動起動をオフにし、画面とキーボードが通常どおり動作することを確認してください。アンインストールすると FoldPatch の設定は消えますが、Shizuku は削除されません。ペアリング・権限・初回インストールは利用者自身の確認が必要で、アプリが無断で許可することはありません。

表示言語は Android の設定に従い、韓国語・英語・日本語・簡体字中国語・繁体字中国語に対応します。表示言語を変えても、日本語や中国語のキーボード入力は追加されません。

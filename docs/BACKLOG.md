# 다음 과제

[English](BACKLOG.en.md) · [현재 검증 결과](RELEASE_REVIEW.md)

다음 작업은 안정성과 설치 편의에 집중합니다. 실기기 근거는 현재 Galaxy Z Fold3 / Android 15에 한정됩니다. 아래는 우선순위이며, 일정이나 다른 기기 지원을 약속하는 목록은 아닙니다.

| 우선순위 | 할 일 | 완료를 판단할 근거 |
| --- | --- | --- |
| alpha.5 공개 전 | 최종 변경 검토와 릴리스 준비 | Fold3 핵심 동작 확인 완료. 공개할 소스·서명 APK·체크섬 일치 확인 |
| 1. Android·One UI 호환성 | 다른 기기에서 보고되는 화면 구조·작업표시줄·제스처·입력 차이 조사 | 모델·OS·빌드·재현 순서와 수정 전후 결과를 기록하고 확인된 범위만 호환성 표에 반영 |
| 2. 연결·접기·복구 | Wi-Fi·모바일 데이터·장시간 대기, 반복 접기/잠금, Shizuku 종료·재시작·재부팅 | 조작이 유지되거나 기본 화면·시스템 제스처·키보드가 복구되는지 확인. 실행 중인 Shizuku 재연결과 종료된 Shizuku 재시작을 구분 |
| 3. 첫 설치 | 삼성 새 설치와 개발자 도움 없이 안내만 따라 하는 사용자 시험, 번역·작은/큰 UI 설정 점검 | 막히거나 이해하기 어려운 단계를 기록하고 개선한 뒤 도움 없이 해당 단계를 다시 완료 |

짧은 집 안 연결 시험, 가상 기기의 사용 준비 및 자동 복구 시험은 통과했습니다. 처음 보고된 외출 중 먹통의 원인, 장시간 대기와 초보자의 설치 성공은 이 결과만으로 확인되지 않습니다. 삼성 작업표시줄 자동 숨김은 설정 재적용으로 복구한 적이 있으며 원인은 미확정입니다.

## 첫 릴리스 준비

서명 APK·체크섬, 빌드 가능한 소스 묶음, 핵심 문서 한·영판, 이슈 양식과 GitHub Actions 구성을 로컬에 준비했습니다. [검증 요약](RELEASE_REVIEW.md)에서 실제 수행한 검사와 아직 GitHub에서 실행하지 않은 검사를 구분합니다.

공개 전에는 서명 키의 별도 안전한 백업을 확인하고, 검토한 소스와 같은 버전의 APK를 태그에 연결해 게시해야 합니다. 실제 다운로드 링크와 GitHub 자동 검사 결과는 게시 후 확인합니다. 스토어 배포는 이번 범위가 아닙니다.

## 이후 작업

- 현재 화면 버퍼 방식의 지연·배터리·발열 측정. 이전 표시 방식의 측정값을 현재 성능으로 제시하지 않습니다.
- 실제 문제가 보고되는 통화·보호 콘텐츠·시스템 대화상자·키보드 전환 점검.
- 한글·영문 키보드의 기호·이모지·입력칸별 사용성 개선. 일본어·중국어 입력과 가로 화면은 뒤로 미룬 기능입니다.
- PiP 추가 잘림은 기본 Android 동작과 비교한 뒤 결함 여부를 판단합니다. 가장자리로 창을 밀어 일부 숨기는 동작 자체는 정상일 수 있습니다.

이미 구현된 기능: 기존 앱 재배치, 정상 터치 쪽 선택, 반대쪽/전체 터치패드, 드래그·핀치·전방향 스크롤·길게 누르기, 포인터·조작바 설정, 한쪽 키보드·편집·햅틱, UI 다국어, 범위 미리보기/원복, 재연결과 접기 복구. 구현 완료가 모든 기기에서의 검증 완료를 뜻하지는 않습니다.

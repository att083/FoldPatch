# 安装与使用 FoldPatch

[English](INSTALL.en.md) · [한국어](INSTALL.md) · [日本語](INSTALL.ja.md) · **简体中文** · [繁體中文](INSTALL.zh-Hant.md)

[返回 README](../README.zh-Hans.md)

FoldPatch 目前为早期 Alpha 版本。真机验证环境为 **Galaxy Z Fold3（SM-F926N）· Android 15 / One UI 7**。Android 16/17 仅在模拟器上测试。长时间使用以及所有系统界面切换尚未验证。Android 14 是最低安装版本，并不代表支持所有设备。[兼容性与验证记录（英文）](COMPATIBILITY.en.md)。

## 1. 获取 APK

请使用可安装的 **`foldpatch-release.apk`**，无需自行编译。点击 **[下载 APK](https://github.com/att083/FoldPatch/releases/download/v0.1.0-alpha.4/foldpatch-release.apk)** 获取安装文件。“Source code (zip)” 不能安装到 Android 上，以 `-unsigned.apk` 结尾的文件也不是面向用户的发布版。

打开 APK 时，Android 可能要求允许浏览器或文件管理应用安装应用。请仅在信任文件来源时允许。两个 APK 使用相同签名密钥时，可以保留设置直接更新。开发版和公开版可能使用不同密钥；遇到签名不匹配时，不要为了绕过错误直接卸载旧版。

## 2. 选择触控正常的一侧

打开 FoldPatch，首次设置会询问 **内屏**哪一侧触控正常。可以折叠手机，在外屏完成这一步。在内屏上，初始操作控件位于左右两端。

设置、触控板、工具栏和键盘会放到所选的一侧。这不会交换应用位置，也不会改变可见宽度。以后更改此设置时，需要在新的一侧确认；未确认的更改会在 15 秒后恢复到原来的一侧。

## 3. 准备 Shizuku

FoldPatch 需要通过独立应用 Shizuku 使用系统显示和输入功能。**不需要 root，也不需要一直连接电脑。**

引导会跳过已完成的步骤，提示你完成剩余准备：

1. 从 [官方下载页面](https://shizuku.rikka.app/download/)安装 Shizuku，然后返回 FoldPatch。
2. 开启 Android 开发者选项。Samsung 手机通常在 **设置 → 关于手机 → 软件信息** 中连续点击 **版本号**；如有要求，请解锁。
3. 连接 **可信的 Wi-Fi**，在开发者选项中开启 **无线调试**。
4. 在 Shizuku 中进入 **通过无线调试启动 → 配对**。打开 Android 的 **使用配对码配对设备**，将配对码输入 **Shizuku 通知**，而不是 FoldPatch。如果这一步需要通知权限，请允许 Shizuku 发送通知。
5. 返回 Shizuku，点击 **启动**。确认显示正在运行后，返回 FoldPatch。
6. 在 Shizuku 权限提示中允许 FoldPatch。如果之前拒绝过，可以重试或从 Shizuku 的已授权应用列表中更改。

不同手机的系统菜单名称可能不同，请按需参考 [Shizuku 官方设置指南](https://shizuku.rikka.app/guide/setup/)。不要在问题反馈中公开配对码或 Wi-Fi 密码。恢复连接不要求使用公共 Wi-Fi。

**手机重启后：** 非 root 方式启动的 Shizuku 服务会停止，可能需要手动重新启动。有条件的自动启动不代表在任何环境中都能自动恢复。FoldPatch 会保留屏幕范围和偏好设置，重新启动 Shizuku 后无需从头调整。

**日常使用时：** FoldPatch 与 Shizuku 的连接在手机本地完成，与电脑的无线 ADB 连接不同。Fold3 已通过短时间断开 Wi-Fi 的测试，但并未验证所有电源和网络条件。如果 Shizuku 停止，请按重新连接的提示操作；FoldPatch 无法替代 Shizuku 的启动流程。

## 4. 授予权限并准备键盘

在 FoldPatch 的设置引导中：

1. 允许 **显示在其他应用上层**，然后返回。
2. 阅读无障碍服务说明，如要继续使用，请同意。
3. 阅读键盘切换说明，如要继续使用，请同意。

开启 FoldPatch 时，会通过 Shizuku 启用 FoldPatch 的无障碍服务并切换到单侧键盘。折叠手机或关闭 FoldPatch 时，会尝试恢复之前的键盘。你可以不同意并退出引导，但此时尚未完成使用准备。

公开发布版没有互联网权限、广告或统计分析 SDK，不保存屏幕图像或输入的文字。少量本地运行诊断记录包含技术状态信息。[隐私与权限详情（英文）](../PRIVACY.en.md)。

## 5. 调整可见宽度

竖向展开手机并解锁，开启 FoldPatch，然后进入 **调整屏幕范围**。

- 刻度以 **未经调整的实际屏幕**为准：两侧各自的外边缘是 **0%**，中间是 **50%**。
- 使用触控正常一侧的两个滑块和 ± 按钮，分别设置从左右外边缘向内可见的宽度。每侧范围为 20–50%，以 0.5% 为步长。
- 打开预览，确认合适后点击 **保存此范围**。未保存时会在 15 秒后恢复之前的范围。
- 完成指针与工具栏练习后，返回平时使用的应用。

如果整个屏幕都能显示，请设为 **左侧 50% · 右侧 50%**。这样会保留原来的全宽画面，不留中间空隙，同时仍可用触控板操作另一侧或整个屏幕。如果两侧触控都正常，选择更方便的一侧即可。

FoldPatch 会记住已完成的准备。如果 Shizuku 之后停止，只会提示需要重新完成的步骤，不会清除屏幕设置。

## 6. 使用触控板

在工具栏中选择触控正常的一侧，可以直接触摸操作这一侧。选择另一侧或整个屏幕时，触控正常的一侧就会变成触控板。

| 操作 | 在触控正常一侧使用的手势 |
| --- | --- |
| 移动 / 点击 | 单指移动 / 不移动手指，轻点一下。 |
| 拖动 | 轻点一次，再次按住并移动；也可以按住直到振动提示后再移动。 |
| 长按 | 将指针对准目标，保持按住。 |
| 滚动 | 双指一起上下、左右或斜向移动。 |
| 缩放 | 将指针对准目标，然后双指张开或捏合。 |
| 双击 | 在同一位置快速轻点两次。 |

手势的具体效果取决于被操作的应用。只有支持缩放的内容才能缩放。

点按工具栏手柄，可依次切换单个按钮、所选按钮和全部按钮；拖动手柄可移动工具栏。可调整大小、方向、显示的按钮和指针速度，并记住展开状态及左右两侧各自的位置。从最下边缘向上滑动会作为系统手势处理，普通触控板操作请从区域内部开始。系统手势的支持情况仍受上述设备与系统验证范围限制。

选择任一输入框即可使用单侧键盘。**键盘仅支持韩语和英语，不支持日语或中文输入。** 在输入框允许的情况下，可使用剪切、复制、粘贴、全选和光标移动。复制或剪切前，请先选择文字。不包含自动补全、语音输入或剪贴板历史记录。

## 恢复、关闭与卸载

| 情况 | 处理方式 |
| --- | --- |
| 正在重新连接 | 稍等片刻。如果 Shizuku 仍在运行且已授权，FoldPatch 可以重新连接。 |
| Shizuku 已停止 / 未授权 | 启动 Shizuku 或授权 FoldPatch，然后重试“检查 Shizuku 连接”。 |
| 无法触及工具栏 | 折叠手机，在外屏打开 FoldPatch 设置。 |
| 屏幕范围不正确 | 未保存的预览可等待超时恢复；已保存的更改，可在“帮助与恢复”中选择“恢复上次保存的范围”。 |
| 想停止使用 | 关闭“使用 FoldPatch”。若不希望自动恢复使用，也关闭“展开时自动开启”。其他应用不会被关闭。 |
| 意外退出后显示仍异常 | 稍等片刻，若未恢复，折叠手机并在外屏打开 FoldPatch。必要时重启手机。 |
| 没有恢复之前的键盘 | 在 Samsung 设置 → 常规管理 → 键盘列表和默认值中重新选择。 |

卸载前，请先关闭 FoldPatch 和自动开启，确认屏幕与键盘恢复正常。卸载会删除 FoldPatch 的设置，但不会卸载 Shizuku。配对、权限和首次安装都需要你本人确认，应用不会静默授予自己权限。

界面语言跟随 Android 设置，支持韩语、英语、日语、简体中文和繁体中文。切换界面语言不会增加日语或中文键盘输入支持。

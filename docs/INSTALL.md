# 처음 설치하는 분을 위한 안내

## 준비할 것

- 확인된 환경: Galaxy Z Fold3 SM-F926N, Android 15, One UI 7.
- 앱 설치 조건은 Android 14 이상입니다. 다른 모델·OS에서는 동작을 보장하지 않습니다.
- **실기기에서 동작을 확인한 환경은 삼성 Galaxy Z Fold3 · Android 15 · One UI 7입니다. Android 16·17은 가상 기기에서만 확인했으며 실기기 테스트는 아직 하지 못했습니다.** 자세한 범위는 [호환성 표](COMPATIBILITY.md)를 참고하세요.
- 선택할 쪽에 정상 터치·표시 영역이 필요합니다. 준비는 가능하면 접힌 바깥 화면에서 진행하세요.
- Shizuku를 시작할 때는 Wi-Fi 연결과 개발자 옵션의 무선 디버깅이 필요합니다.

## 1. APK 다운로드 및 설치

한국어 환경에서는 앱 목록·권한 창에 **폴드패치**로 표시됩니다. 다른 지원 언어에서는 **FoldPatch**입니다. 기존 ReachPad 개발판과 같은 앱이며, 같은 서명의 APK는 삭제 없이 업데이트할 수 있습니다.

설치용 파일은 **`foldpatch-release.apk`**입니다. 직접 빌드할 필요가 없습니다. GitHub 릴리스가 게시되면 저장소의 **Releases → Assets**에서 받으세요. 첫 공개 릴리스 게시를 준비 중입니다.

**Source code (zip)**은 소스 코드이며, 이름에 **unsigned**가 들어간 APK는 서명 전 파일입니다. 설치용 APK를 선택하세요.

APK를 열고 설치를 진행합니다. Android가 설치를 막으면 APK를 연 브라우저 또는 파일 앱에 대해 ‘알 수 없는 앱 설치 → 이 출처 허용’을 요청할 수 있습니다. 휴대전화의 보안 설정에 따라 메뉴가 다릅니다. 경고가 다른 앱이나 다른 서명을 가리킨다면 진행하지 말고 파일 출처를 다시 확인하세요.

설치 후 폴드패치를 열면 **사용 준비**에서 Shizuku 설치·시작부터 순서대로 안내합니다. 아래는 그 단계의 상세 설명입니다.

## 2. Shizuku 설치 및 시작

[Shizuku 공식 다운로드](https://shizuku.rikka.app/download/)에서 설치하세요.
Shizuku는 FoldPatch가 화면 배치와 입력 전달에 필요한 시스템 기능을 사용할 수 있게 연결합니다.

1. 삼성 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호를 여러 번 눌러 개발자 옵션을 활성화합니다. 잠금 해제를 요청할 수 있습니다.
2. 개발자 옵션에서 무선 디버깅을 켭니다.
3. Shizuku의 **무선 디버깅으로 시작 → 페어링** 안내를 따릅니다.
4. 시스템의 **페어링 코드로 기기 페어링**에서 받은 코드를 Shizuku 알림에 입력합니다. 코드를 GitHub나 다른 사람에게 보내지 마세요.
5. Shizuku로 돌아와 **시작**을 누르고 실행 중인지 확인합니다.

페어링 알림이 사라졌다면 Shizuku에서 **페어링**을 다시 열고 진행하세요. 폴드패치에서 개발자 옵션이 아직 꺼져 있다고 안내하면, 빌드번호를 눌러 활성화한 뒤 돌아와 **했어요 · 다음**을 누르세요.

제조사·버전별 차이와 자세한 화면은 [Shizuku 공식 사용 설명](https://shizuku.rikka.app/guide/setup/)을 확인하세요. 비루팅 방식은 재부팅하면 기존 서비스가 종료됩니다. Shizuku 13.6은 Android 13 이상에서 조건이 맞으면 신뢰한 Wi-Fi를 통해 부팅 시 시작을 시도하지만, 항상 자동 복구된다고 보장하지 않습니다. 일반적인 사용 중에는 컴퓨터가 필요하지 않습니다.

## 3. 앱에서 한 단계씩 준비하기

처음 실행하면 **사용 준비**가 자동으로 열립니다. 먼저 내부 화면에서 터치되는 쪽을 선택하세요. 펼친 상태에서는 양쪽 가장자리에 시작 버튼이 표시되고, 접은 상태에서도 선택할 수 있습니다. 이후 준비는 바깥 화면에서 진행하면 편합니다.

1. Shizuku가 없다면 **공식 다운로드 열기**로 설치합니다. 설치 뒤 폴드패치로 돌아오세요.
2. Shizuku가 꺼져 있다면 개발자 옵션 → 신뢰하는 Wi-Fi와 무선 디버깅 → 페어링·시작을 순서대로 안내합니다. 이미 준비했다면 다음으로 넘길 수 있습니다. 실행 중이면 이 단계는 자동으로 건너뜁니다.
3. **연결 허용하기**를 누르고 Shizuku 권한 창에서 폴드패치를 허용합니다. 허용을 거절했다면 다시 시도하거나 Shizuku의 허가된 애플리케이션에서 허용하세요.
4. **다른 앱 위에 표시** 설정에서 폴드패치를 허용하고 돌아옵니다. 권한 상태를 다시 확인하므로 같은 스위치를 반복해서 켤 필요가 없습니다.
5. **접근성 기능**과 **키보드 전환** 설명을 각각 읽고 동의합니다. 폴드패치를 켜면 Shizuku를 통해 접근성 서비스를 활성화하고 정상 터치 쪽의 키보드로 전환합니다. 이 동작에 동의하지 않으면 ‘나중에 준비하기’로 나갈 수 있습니다.
6. 폰을 세로로 펼쳐 **폴드패치 켜기 → 화면 범위 맞추기**를 진행합니다. 미리보기를 저장해야 다음으로 넘어갑니다. 취소하거나 시간이 지나면 범위 조정 단계에 머뭅니다.
7. 연습 영역에서 포인터 이동·클릭과 조작바 펼치기를 익힙니다. 마지막 화면에서 자동 시작과 알림 허용을 선택하고 **폴드패치 사용하기**를 누릅니다.

다른 설정이나 Shizuku에 다녀와도 끝낸 단계는 기억합니다. **나중에 준비하기**로 나왔을 때는 홈의 **사용 준비**에서 이어갈 수 있습니다. Shizuku가 꺼지거나 권한이 취소되면 필요한 준비만 다시 보여 줍니다. 화면 범위와 개인 설정은 초기화하지 않습니다. 기존 버전에서 준비를 마친 사용자는 튜토리얼을 다시 진행하지 않습니다.

페어링 코드는 Shizuku 알림에만 입력하세요. 폴드패치는 코드를 요구하거나 저장하지 않습니다. 설치와 권한의 실제 허용은 사용자가 직접 해야 합니다. 공용 Wi-Fi를 복구 수단으로 요구하지 않습니다. 제조사별로 준비가 차단되는 경우 보호 설정을 무조건 해제하지 말고 공식 안내를 확인하세요.

**Shizuku 연결 확인**은 폴드패치를 켜거나 끄는 버튼이 아닙니다. 이미 연결되어 있으면 버튼 위에 ‘연결 확인 완료 · 정상 연결’을 표시합니다. 권한이 없으면 허용 단계로, Shizuku가 실행되지 않았으면 Shizuku 앱으로 안내합니다. 연결 중에는 상태가 자동으로 갱신되며, 재연결을 시도한 뒤 8초가 지나도 연결되지 않으면 실행 상태 확인과 재시도를 안내합니다.

배포 및 권한 관련 검토 범위는 [Shizuku 정책 검토](SHIZUKU_POLICY.md)를 참고하세요. GitHub 배포 준비와 Google Play 등록 승인은 별개입니다.

## 4. 터치가 되는 쪽 선택

설정의 **터치가 되는 쪽**에서 왼쪽 또는 오른쪽을 고릅니다. 설정 화면·범위 조정 버튼·키보드·조작바·터치패드가 선택한 쪽으로 옮겨집니다. 화면의 내용과 양쪽 폭은 바뀌지 않습니다.

옮겨진 화면에서 **이쪽에서 사용할게요**를 눌러 저장합니다. 확인하지 않으면 15초 후 원래 쪽으로 돌아갑니다. 화면을 나가도 미확정 변경은 취소합니다. 잘못 고른 쪽이 터치되지 않아도 기다리면 복구됩니다. 바깥 화면에서 선택할 수도 있습니다.

왼쪽·오른쪽의 조작바 위치는 각각 기억합니다. ‘전체’ 모드는 그대로 유지하고, 일반 터치/반대쪽 터치패드 모드는 선택한 쪽에 맞춰 바뀝니다.

## 5. 화면 범위 맞추기

1. 세로로 펼치고 잠금을 해제합니다. 폴드패치가 **사용 중**이 되면 **화면 범위 맞추기**를 엽니다.
2. 이 화면은 보정 전의 실제 화면입니다. 왼쪽 끝·오른쪽 끝이 각각 **0%**, 가운데가 **50%**입니다.
3. 선택한 쪽의 두 슬라이더와 **− / +** 버튼으로 양쪽에 실제 보이는 폭을 맞춥니다. 각쪽 20~50%를 0.5%씩 조절합니다.
4. **미리보기**를 누르고 정상적으로 보이면 **이 범위로 저장**을 누릅니다.
5. 저장하지 않으면 15초 뒤 이전 범위로 돌아갑니다. 설정의 **도움 및 복구**에서 이전 저장 범위로 복구할 수도 있습니다.

화면 전체가 보인다면 **왼쪽 50% · 오른쪽 50%**로 맞추세요. 가운데 빈 구간 없이 원래 화면 전체를 사용하면서 한쪽 터치패드로 반대쪽이나 전체 화면을 조작할 수 있습니다. 양쪽 모두 터치가 된다면 조작하기 편한 쪽을 선택하세요.

## 6. 조작

- **정상 터치 쪽:** 조작바에서 같은 쪽을 고르면 직접 터치합니다.
- **반대쪽 / 전체:** 정상 터치 쪽의 빈 곳에서 한 손가락으로 포인터를 움직입니다. 제자리에서 톡 누르면 클릭합니다. 두 손가락으로 상하·좌우·대각선 스크롤합니다.
- **드래그:** 한 번 톡 누른 뒤 다시 누른 채 끌거나, 가만히 누른 뒤 진동이 오면 끕니다. 계속 누르고 있으면 대상 앱의 길게 누르기가 동작합니다.
- **확대·축소:** 포인터를 원하는 곳에 놓고 두 손가락을 벌리거나 오므립니다. 확대 가능한 사진·지도·웹페이지 등에서 사용하세요.
- **더블클릭:** 같은 곳을 빠르게 두 번 톡 누릅니다. 대상 앱에 따라 확대 등으로 동작할 수 있습니다.
- **조작바 손잡이:** 누를 때마다 완전 접힘(버튼 하나) → 펼침(설정에서 선택한 버튼) → 완전 펼침(설정 포함 모든 버튼) → 완전 접힘으로 바뀝니다. 손잡이를 끌면 조작바가 움직입니다. 완전히 접어도 터치패드와 화면 지원은 계속 동작합니다. 마지막 접힘 단계와 좌우 각각의 위치를 기억합니다. 설정·잠금 화면에 다녀오거나 앱을 다시 시작해도 유지하며, 펼치느라 잠시 밀린 위치는 다시 접으면 돌아옵니다.
- **화면 아래쪽 끝에서 시작한 제스처:** 홈·최근 앱 제스처로 전달합니다. 영역 안쪽은 터치패드 조작입니다.
- **키보드:** 입력칸을 선택하면 정상 터치 쪽에 나타납니다. ‘키보드 ▾’로 닫습니다.

### 키보드 편집 도구

키보드의 **편집** 버튼을 누르면 잘라내기·복사·붙여넣기·전체 선택과 좌우 커서 이동 버튼이 나타납니다. 다시 누르면 도구가 접힙니다. 복사·잘라내기는 먼저 편집할 글자를 선택하세요. 한글을 조합 중이면 글자를 확정한 뒤 편집합니다. 도구는 현재 입력 중인 앱의 입력칸에 적용되며, 해당 앱이 제한한 편집 기능은 사용할 수 없습니다.

## 문제 해결과 끄기

| 증상 | 할 일 |
| --- | --- |
| 다시 연결하는 중 | 잠시 기다리면 살아 있는 Shizuku에 다시 연결합니다. Shizuku 자체가 꺼졌거나 권한이 없으면 해당 안내를 따릅니다. |
| 연결 필요 | Shizuku 실행 여부와 FoldPatch 권한을 확인하고 ‘Shizuku 연결 확인’을 누릅니다. |
| 바깥 화면에서 대기 | 세로로 펼치고 잠금을 해제합니다. |
| 조작바를 찾기 어려움 | 폰을 접고 바깥 화면에서 FoldPatch 앱을 엽니다. |
| 화면 범위를 잘못 맞춤 | 미리보기는 저장하지 말고 기다립니다. 저장한 값은 도움 및 복구에서 이전 범위로 되돌립니다. |
| 폴드패치를 완전히 끄고 싶음 | **폴드패치 사용**과 **펼치면 자동으로 켜기**를 모두 끕니다. |
| 앱 종료 뒤 화면이 이상함 | 잠시 기다려 복구되는지 확인하고, 접어 바깥 화면에서 FoldPatch를 다시 엽니다. 필요하면 휴대전화를 재시작합니다. |
| 이전 키보드로 돌아가지 않음 | 삼성 설정 → 일반 → 기본 키보드 및 추가 키보드 설정에서 이전 키보드를 직접 선택합니다. |
| 재부팅 뒤 실행되지 않음 | Shizuku를 다시 시작하고 FoldPatch를 엽니다. 재부팅 직후 무인 자동 복구는 보장하지 않습니다. |

## 업데이트와 삭제

같은 서명으로 배포된 새 APK를 기존 앱 위에 설치하면 설정이 유지됩니다. 개발용 APK와 공개 APK는 서명이 달라 덮어 설치되지 않을 수 있습니다. 이런 경우 먼저 폴드패치·자동 시작을 끄고 화면 범위·조작 설정을 기록하세요. 삭제하면 앱 설정도 삭제됩니다. 개발용 사용자를 위한 설정 내보내기 기능은 아직 없습니다.

삭제 전 폴드패치와 자동 시작을 끄고 원래 화면·키보드로 돌아왔는지 확인하세요. FoldPatch만 삭제한다고 Shizuku까지 삭제되지는 않습니다.

## 표시 언어

OS의 언어 설정을 자동으로 따릅니다. 한국어·영어·일본어·중국어 간체/번체를 지원합니다. Android의 앱별 언어 설정에서도 변경할 수 있습니다. 키보드 입력은 한글·영문만 가능하며, 표시 언어를 바꿔도 일본어·중국어 입력 기능이 추가되지는 않습니다.
